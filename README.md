# Sky Rush — аркадные 3D-гонки в браузере

Аркадная гонка по трассам в небе. Игра работает в браузере на ПК и на мобильных.
**Все ассеты генерируются кодом**: трассы, машины, текстуры, окружение, музыка и звуки.
Внешних файлов нет. Сборка весит около 210 КБ (gzip).

План разработки: [PLAN.md](PLAN.md).

## Запуск

```bash
npm install
npm run dev        # dev-сервер: http://localhost:5173
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # просмотр production-сборки
npm test           # unit-тесты генератора уровней (vitest)
```

`dist/` — это статический бандл (index.html + 1 js + 1 css). Его можно загрузить на любой игровой портал.

## Управление

| ПК | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз |
| A D / ← → | руль |
| Пробел / Shift / N | нитро |
| Esc / P | пауза |
| M | звук вкл/выкл |
| Геймпад | стик — руль, RT — газ, LT — тормоз, A/RB — нитро, Start — пауза |

**Мобильные (газ ручной):**
- палец на экране — газ;
- палец на левой половине — газ и поворот влево, на правой — газ и поворот вправо;
- оба пальца — газ прямо;
- отпустили — тормоз;
- кнопка NOZ справа — нитро.

В настройках есть вторая схема: «свайп пальцем». Палец держится на экране (газ), а движение влево-вправо работает как руль.

## Геймплей

- 6 машин в заезде: игрок стартует последним. Над соперниками висят флажки с их местом.
- Слишком быстро в повороте — машину заносит наружу. Без бортика она вылетает с трассы, у бортика теряет скорость. Сброс газа и тормоз перед поворотом — главный навык.
- **Сердца**: в начале 3. Сердце теряется за вылет с трассы или удар о препятствие. 0 сердец — **GAME OVER**. На экране геймовера кнопки:
  - «Возродиться» (за ревардед, до 2 раз за заезд, кнопка исчезает через 8 с);
  - «Начать сначала»;
  - «Магазин»;
  - «Главное меню».
- **Подбираемые предметы**:
  - монеты;
  - звёзды очков (с комбо);
  - сердца;
  - канистры нитро;
  - щит;
  - магнит;
  - x2;
  - кристаллы.
  Ещё есть буст-пады — стрелки на асфальте.
- **Препятствия**:
  - конусы;
  - бочки;
  - барьеры;
  - контейнеры;
  - катящиеся пляжные мячи в трубах.
- Нитро-шкала перезаряжается сама, быстрее в заносе и в прыжке.
- Финиш в тройке открывает следующий уровень. ★★★ — за 1-е место, ★★ — за 2-е, ★ — за 3-е.

## Бесконечные уровни

`src/world/track/TrackGenerator.ts` строит трассу по номеру уровня. Генерация детерминирована: уровень N всегда одинаковый.

Трасса собирается из сегментов:
- прямые;
- повороты с наклоном;
- S-кривые;
- горки и «волны»;
- трамплины с разрывом;
- мёртвые петли;
- сужения;
- водные трубы (half-pipe).

Сложность растёт плавно: повороты становятся круче, бортиков меньше, препятствий больше, боты быстрее. Уровни 1–2 щадящие.

Биом меняется каждые 5 уровней: Небесный океан → Порт → Мосты → Водные горки → Каньон → Неон-сити → Снежные пики → Вулкан. Каждый 10-й уровень — гонка с боссом на эксклюзивной машине Inferno.

## Экраны

1. Загрузка.
2. Главное меню: 3D-подиум с машиной, приз дня, колесо удачи.
3. **Карта уровней**: бесконечная, со звёздами, сундуками каждые 5 уровней и боссами.
4. **Магазин**. Вкладки:
   - 15 машин;
   - 21 краска (глянец, металлик, мат, хром, карбон, хамелеон);
   - 9 винилов;
   - 8 дисков;
   - неон днища;
   - цвета нитро;
   - бустеры;
   - бесплатные монеты.
5. **Гараж**: прокачка 4 характеристик машины до 10 уровня.
6. **Подготовка к заезду**: бустеры (старт с нитро, щит, +сердце, магнит, монеты x2) и тест-драйв машины за рекламу.
7. HUD:
   - место;
   - спидометр;
   - прогресс до финиша;
   - сердца;
   - монеты;
   - очки;
   - активные бонусы;
   - кнопка NOZ;
   - пауза;
   - отсчёт.
8. Пауза, результат заезда, GAME OVER, настройки.

## Реклама

Архитектура в `src/ads/`:

- `AdProvider.ts` — интерфейс, который реализует адаптер площадки: `showInterstitial`, `showRewarded`, `gameplayStart/Stop`, `loadingFinished`, `happyTime`.
- `providers/MockProvider.ts` — **заглушка**. Показывает полноэкранную «рекламу» с таймером: интерстишл 4 с, ревардед 6 с (ревардед можно закрыть раньше, тогда награды нет).
- `AdPolicy.ts` — частота показов. Минимум 45 с между интерстишлами, первые 60 с без рекламы, 30 с тишины после ревардеда, интерстишлы начиная с 3-го уровня.
- `AdService.ts` — фасад для игры. Перед интерстишлом показывает плашку «Реклама». Награда выдаётся **только** при результате `rewarded`. Если реклама не загрузилась или упала, показывается тост.

**Интерстишл** (агрессивность выше среднего):
- после каждого завершённого уровня;
- при «Начать сначала» / «Повторить»;
- при выходе в меню из паузы или геймовера;
- при переходе из меню в карту или магазин;
- при переходе из геймовера в магазин.

**Ревардед**:
- возрождение;
- x3 награда за уровень;
- пропуск уровня;
- бесплатные монеты (лимит в день);
- открытие машин, красок, винилов, дисков, неона и нитро за N просмотров;
- тест-драйв машины;
- бесплатный бустер;
- бесплатная прокачка;
- x2 приз дня;
- x2 сундук;
- x2 награда колеса;
- дополнительное вращение колеса.

Баннеров нет.

**Общие правила (реализованы):**
- Во время рекламы игровой цикл остановлен, `AudioContext.suspend()` и звук выключен, ввод заблокирован, «залипшие» клавиши сброшены. После возрождения заезд продолжается с отсчёта.
- Отключены ПКМ / контекстное меню / долгий тап, выделение текста, перетаскивание, зум (pinch, double-tap, ctrl+колесо), скролл страницы и pull-to-refresh, автоскролл средней кнопкой.
- Стрелки и пробел не прокручивают страницу.
- Свернули вкладку или окно потеряло фокус — звук выключается, заезд встаёт на паузу.
- Звук стартует только после первого нажатия.
- Во время активного заезда реклама не показывается.

### Как подключить реальную площадку

1. Создать `src/ads/providers/<Platform>Provider.ts`, реализующий `AdProvider`. Пример: адаптер вызывает SDK площадки и превращает его колбэки в `Promise<'shown' | 'rewarded' | 'closed' | 'error' | 'no_fill'>`.
2. В `src/core/Game.ts` заменить `new MockProvider(...)` на новый провайдер. Можно выбирать провайдер по переменной окружения сборки.
3. При необходимости поправить `DEFAULT_POLICY` в `AdPolicy.ts` под требования площадки.

## Технологии

- **TypeScript + Vite + Three.js**.
- Своя кинематическая физика по сплайну трассы: координаты (s, d, h), занос с инерцией, прыжки, вылеты.
- Рендер:
  - PBR (MeshPhysicalMaterial с лаком у краски);
  - отражения от процедурного неба через PMREM;
  - мягкие тени;
  - тонмаппинг;
  - bloom, FXAA, радиальное размытие на нитро;
  - процедурные небо, облака, вода и лава в шейдерах.
- Звук — Web Audio:
  - синтез всех эффектов;
  - мотор с «коробкой передач»;
  - ветер и визг шин;
  - секвенсор с 9 стилями музыки (по биомам и для меню);
  - мелодии генерируются по номеру уровня.
- Пресеты графики Low/Medium/High. Авто-определение на мобильных и авто-понижение, если FPS низкий.
- Сохранения в `localStorage` с резервной копией (`src/meta/SaveService.ts`).
- **Два языка: русский и английский** (`src/i18n/i18n.ts`). При первом запуске язык берётся из браузера. Переключатель **RU / EN** стоит в правом верхнем углу главного меню, ещё один — в «Настройках» (доступны и из паузы). Выбор сохраняется. Переведены все экраны, названия красок, винилов, дисков, неона и нитро, флажки мест, HUD и заглушка рекламы. Названия машин — бренды, они не переводятся.

## Структура

```
src/
  core/      Game (оркестратор), Input, PageGuard, Rng, EventBus
  render/    Renderer + постобработка, Sky, Ground (вода/лава), Particles, процедурные текстуры
  world/     TrackGenerator, TrackData, TrackMesh, Environment (биомы), Showroom, Biomes
  vehicles/  CarModel (процедурная модель), Livery (раскраски)
  gameplay/  Race (правила, физика, ИИ), Racer, Pickups, Obstacles, ChaseCamera
  audio/     AudioEngine, Sfx, EngineSound, Music
  ads/       AdProvider, AdService, AdPolicy, MockProvider
  meta/      Catalog (контент магазина), Economy, SaveService, Analytics
  ui/        UI-менеджер, экраны (screens/*), стили
scripts/     QA-скрипты Playwright (скриншоты, сценарии, баланс)
tests/       unit-тесты
```

## QA-параметры URL

| Параметр | Что делает |
|---|---|
| `?ads=fast` | реклама-заглушка длится 1 с |
| `?ads=nofill` / `?ads=error` | симуляция отсутствия или ошибки рекламы |
| `?adpolicy=test` | интерстишлы без задержек и кулдаунов |
| `?ts=N` | N шагов симуляции за кадр (ускорение для медленных headless-прогонов) |

В консоли доступен `window.game`. Например, `game.race.autoPlayer = true` включает автопилот.

QA-скрипты (нужен запущенный `npm run dev`):

```bash
node scripts/flow.mjs shots/                     # полный сценарий: меню → гонка → результат → реклама → геймовер → возрождение → пауза → магазин...
node scripts/adflow.mjs shots/                   # правила рекламы
node scripts/balance.mjs '[1,5,10,20]' hold      # баланс: «просто жать газ»
node scripts/biomes.mjs shots/ '[[12,"loop"]]'   # скриншоты биомов и сегментов
node scripts/lang.mjs shots/                     # переключение RU/EN
node scripts/touch.mjs                           # мобильное управление
```
