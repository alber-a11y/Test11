# Sky Rush — план разработки

Аркадная 3D-гонка по трассам в небе (референсы: Race Master 3D / Car Race 3D).
Платформы: браузер на ПК и на мобильных. Все ассеты (модели, текстуры, музыка, звуки) генерируются кодом.

---

## 1. Технологии

| Задача | Выбор | Почему |
|---|---|---|
| Язык | **TypeScript** | типы, автодополнение, меньше ошибок в большом проекте |
| Сборка | **Vite** | мгновенный dev-сервер, сборка в один статический бандл, который можно загрузить на любой портал |
| 3D | **Three.js** (r16x+) | самый простой и документированный WebGL-движок, есть PBR, тени, инстансинг, постобработка |
| Постобработка | `three/examples` EffectComposer: Bloom, ACES tone mapping, FXAA/SMAA, Vignette | «сочная» картинка как на референсах и лучше |
| Физика | **своя кинематика по сплайну** (без физдвижка) | в аркадной гонке по трассе это проще, стабильнее и быстрее, чем Rapier/Cannon |
| UI / экраны | **HTML + CSS поверх canvas** (без фреймворка, лёгкие компоненты на TS) | адаптивная вёрстка, шрифты, анимации кнопок дешевле, чем рисовать UI в WebGL |
| Звук и музыка | **Web Audio API**: синтез + собственный секвенсор | без файлов, полный контроль громкости и паузы |
| Сохранения | `localStorage` через слой `SaveService` (потом его можно заменить на облачные сохранения платформы) | |
| Тесты | Vitest (логика, генератор), Playwright (smoke-тесты экранов и рекламных сценариев) | |

Целевая производительность: 60 FPS на ПК, ≥ 45–60 FPS на мобильных среднего уровня. Стартовый бандл ≤ 1.5 МБ gzip (ассетов нет, так что это реально).

## 3. Геймплей

### 3.1 Базовая механика (как в референсах)
- Трасса висит в небе / над водой / в порту. 6 участников (игрок + 5 ботов), у каждого над машиной флажок с местом («2ND», «5TH»).
- HUD: слева сверху **POS 6TH**, справа сверху **спидометр km/h** с жёлтой дугой, по центру **LEVEL N** и **полоса прогресса до финиша** с клетчатым флагом, справа кнопка **NOZ** с числом зарядов и круговым индикатором перезарядки. Плюс сердца, счёт очков, монеты за заезд.
- Машина едет вперёд по трассе. Игрок управляет **газом/тормозом и рулём**. Риск: слишком быстро в повороте — вылет с трассы; слишком медленно — обгоняют.

### 3.2 Модель движения (своя кинематика)
- Позиция машины = `(s, d)`: `s` — пройденная дистанция вдоль сплайна, `d` — боковое смещение. Мировая позиция берётся из `TrackQuery` (точка + базис касательная/нормаль/бинормаль), поэтому петли, трубы и банкинги работают «сами».
- Скорость: разгон по кривой с убыванием к `maxSpeed`, тормоз, сопротивление, нитро добавляет `+40% maxSpeed` на 2.5 с.
- Боковая перегрузка: `lateral = v² · curvature`. Если превышает `grip` машины, машину сносит наружу (дрифт с дымом); если она выходит за край без бортика — **вылет** (падение с камерой slow-mo).
- Прыжки: на сегментах «трамплин/разрыв» машина переходит в состояние `airborne` с баллистикой; приземление вне трассы — вылет.
- Столкновения с ботами: упругое отталкивание по `d`, лёгкая потеря скорости. С препятствиями — потеря сердца, отскок, кратковременная неуязвимость (мигание).
- Респаун после вылета: эффект «телепорта» на ближайший безопасный чекпоинт, −1 сердце, −скорость.

### 3.3 Сердца и геймовер
- В начале заезда 3 ❤ (+1 за бустер «Extra Heart»).
- −1 ❤: вылет с трассы, лобовое столкновение с препятствием, попадание под падающий контейнер и т.п.
- **0 ❤ → GAME OVER** (машина взрывается/кувыркается, slow-mo, затем экран).
- Отдельно: финиш ниже 3-го места = «уровень не пройден» (экран результата с кнопками «Повторить» / «Пропустить уровень за рекламу»).

### 3.4 Подбираемые предметы (pick-ups)
| Предмет | Вид | Эффект |
|---|---|---|
| Монета | вращающаяся золотая монета, ряды/змейки | +1 монета (валюта магазина) |
| Звезда очков | голубая звезда | +100 очков, комбо-множитель при подборе подряд |
| Сердце | красное сердце с пульсацией | +1 ❤ (макс. 5) |
| Канистра нитро | баллон «NOZ» | +1 заряд нитро (макс. 3) |
| Буст-пад | стрелки-шевроны на асфальте | мгновенное ускорение без траты нитро |
| Щит | голубой пузырь | 5 с неуязвимости, сносит препятствия |
| Магнит | подкова | 8 с притягивает монеты/звёзды |
| x2 | значок «x2» | 10 с двойные монеты и очки |
| Кристалл (редкий) | фиолетовый кристалл | прогресс к сундуку на карте уровней |

Расстановка — генератором: «линии» вдоль траектории, «приманки» на рискованных траекториях (внешний край поворота, над трамплином).

### 3.5 Препятствия
Бочки, дорожные конусы, шлагбаумы, катящиеся пляжные мячи (как на скрине с трубой), сдвигающиеся контейнеры в порту, вращающиеся молоты, сужения, участки без бортиков, «масляные пятна» (снижают сцепление).

### 3.6 Боты
- 5 ботов с «характерами» (агрессивный, аккуратный, рандомный).
- Rubber-banding: бот, отставший сильно, чуть ускоряется; лидер — замедляется, чтобы гонка всегда была плотной.
- Сложность ботов растёт с уровнем (скорость, точность прохождения поворотов, использование нитро).
- Боты тоже могут вылетать (зрелищно и даёт игроку шанс).

### 3.7 Очки и звёзды
- Очки: дистанция + звёзды + обгоны + дрифт + прыжки (время в воздухе) + нитро-комбо.
- Звёзды уровня (для карты): ★ — финиш в топ-3, ★★ — топ-2, ★★★ — 1-е место. Нужны для открытия сундуков и некоторых машин.

## 4. Бесконечная генерация уровней

### 4.1 Детерминизм
`seed = hash(levelNumber)`. Уровень N всегда одинаковый — можно переигрывать, карта уровней стабильна.

### 4.2 Генератор трассы
Трасса = цепочка **сегментов**, каждый описывает кусок сплайна (контрольные точки + профиль + флаги).

Библиотека сегментов:
- прямая; поворот (лево/право, радиус); S-образная «змейка»;
- подъём / спуск (горка-«американские горки», как на скрине Level 27);
- банкинг (наклонный вираж);
- трамплин + разрыв (прыжок);
- **мёртвая петля**; спираль вверх/вниз;
- **труба / водяная горка** (полузакрытый жёлоб, как Level 12);
- полу-труба (half-pipe), волны-кочки;
- сужение, развилка на 2 пути (короткий рискованный / длинный безопасный);
- финишная прямая с аркой и клетчатыми флагами.

Правила: стыковка по касательной (C¹-непрерывность), проверка самопересечений (bbox-сетка), бюджет сложности на уровень, «передышки» после тяжёлых сегментов.

### 4.3 Кривая сложности
- Длина трассы: 1.2 км → 3 км к 50-му уровню, далее плато с колебаниями.
- Доля сложных сегментов, количество препятствий, мест без бортиков, скорость ботов — растут логарифмически.
- Каждый **5-й** уровень — смена биома. Каждый **10-й** — «Босс-гонка»: 1 соперник-«босс» на эксклюзивной машине, повышенная награда, гарантированный сундук.
- Иногда особые режимы: «Нокаут» (последний выбывает на чекпоинте), «На время», «Сбор монет».

### 4.4 Биомы (окружение генерируется кодом)
| Биом | Трасса | Окружение |
|---|---|---|
| Sky Ocean | оранжево-жёлтые полосы (Level 13) | океан-шейдер, песчаные острова, облака |
| Port | асфальт, красно-белая разметка (Level 23) | стопки контейнеров (инстансинг, вымышленные логотипы), грузовое судно, краны |
| Water Slide | голубой полупрозрачный жёлоб (Level 12) | подводный свет, пузыри, мячи |
| Bridge | асфальт с жёлтой линией (Level 27) | стальные фермы, ванты, рыжие балки |
| Desert Canyon | терракота | скалы low-poly, кактусы, пыль |
| Neon City (ночь) | тёмный асфальт с неоновыми краями | небоскрёбы с окнами-эмиссией, сильный bloom |
| Snow Peaks | лёд (меньше сцепления) | горы, ели, снег-частицы |
| Volcano | тёмный камень | лава-шейдер, искры, дым |

### 4.5 Стриминг
Трасса строится чанками по ~100 м: впереди генерируются 3–4 чанка, позади удаляются. Пропсы окружения — через `InstancedMesh` и пулы объектов.

## 5. Графика (цель — «как референс или лучше»)

### 5.1 Рендер
- `MeshStandardMaterial` / `MeshPhysicalMaterial` (clearcoat у кузова — тот самый «глянец» с бликами).
- ACES Filmic tone mapping, sRGB, одна направленная лампа с мягкими тенями (каскад только вокруг игрока), hemisphere light под цвет неба, **PMREM-окружение из процедурного неба** — даёт настоящие отражения на машинах.
- Туман по биому, градиентное небо + облака (шейдер с fbm-шумом), «speed lines» в небе как на скринах.
- Постобработка: Bloom (неон, фары, нитро), FXAA, лёгкая виньетка, радиальное размытие и расширение FOV при нитро/высокой скорости.
- Пресеты качества Low / Medium / High, автоопределение по GPU и FPS первых секунд (динамический DPR 0.75–2).

### 5.2 Машины (процедурные модели)
- Кузов: лофт по 8–12 поперечным сечениям вдоль длины (параметры: длина, ширина, высота крыши, наклон стёкол, форма капота, спойлер), сглаживание нормалей. Это даёт формы «суперкар», «маслкар», «жук», «спорткупе», «JDM» как на скринах.
- Отдельно: стёкла (тёмный физический материал), фары/фонари (эмиссия + bloom), решётка радиатора, диффузор, выхлопные трубы, антикрыло.
- Колёса: шина (LatheGeometry с протектором-нормалкой из canvas), диски 6–8 дизайнов (спицы генерируются).
- Раскраска через canvas-текстуры: гоночные полосы, номера, огонь, камуфляж, шахматка, градиенты.
- Неоновая подсветка днища (зелёная/красная/фиолетовая, как на скринах) — эмиссивная плоскость + точечный свет.
- Детали анимации: вращение колёс, поворот передних колёс, крен кузова в повороте, «приседание» при разгоне, огонь из выхлопа при нитро.

### 5.3 Процедурные текстуры (CanvasTexture)
Асфальт с шумом и трещинами, красно-белые бордюры, разметка, шевроны буст-падов, гофрированные контейнеры с логотипами, шахматный финиш, металлические фермы, вода-нормали. Генерируются один раз при загрузке и кэшируются.

### 5.4 Эффекты
Дым шин при дрифте, искры при касании бортика, пламя и след нитро (меняется в магазине), брызги в водяной горке, конфетти на финише, взрыв/кувырок при геймовере, «пыль» приземления.

## 6. Управление

### 6.1 ПК
| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз / задний ход при остановке |
| A / ← , D / → | руль |
| Space / Shift | нитро |
| Esc / P | пауза |
| M | вкл/выкл звук |
| R | рестарт (из паузы) |
| Enter | подтверждение в меню |
Опционально — геймпад (Gamepad API).

### 6.2 Мобильные (адаптивные тапы с двух сторон, **газ ручной**)
- Экран делится на **левую и правую зоны** (по 50% ширины).
- **Палец на экране — газ.** Палец в левой зоне — газ и поворот влево, в правой — газ и поворот вправо, оба пальца — газ прямо.
- **Отпустил — тормоз** (ключевой навык перед крутыми поворотами).
- Кнопка **NOZ** справа (как на скринах).
- Зоны учитывают ориентацию и safe-area (вырезы, «чёлки»). При первом запуске — подсказка-туториал.
- Настройка: «Тапы слева/справа» или «Свайп пальцем» (держишь палец — газ, ведёшь влево-вправо — руль).
- Портретная ориентация основная; в ландшафте камера и HUD перестраиваются.

## 7. Экраны

1. **Загрузка** — логотип, прогресс генерации текстур/моделей, «Нажмите, чтобы начать» (нужно для разблокировки AudioContext).
2. **Главное меню** — 3D-витрина текущей машины на вращающемся подиуме; кнопки: «ИГРАТЬ» (уровень N), «Карта», «Магазин», «Гараж», «Ежедневный приз», «Колесо удачи», «Настройки»; счётчики монет/кристаллов.
3. **Карта уровней** — вертикальная извилистая дорога с узлами-уровнями (бесконечная, генерируется по мере прокрутки), звёзды на пройденных, иконки биомов, сундуки каждые 5 уровней, «боссы» каждые 10, текущий уровень пульсирует. Можно переиграть любой пройденный.
4. **Магазин** — вкладки: Машины / Покраска / Диски / Неон / Следы нитро / Бустеры / Монеты (бесплатно за рекламу). Карточка с 3D-превью, ценой в монетах или кнопкой «📺 Смотреть» (прогресс «2/3 рекламы»).
5. **Гараж** — выбор и примерка купленного, характеристики машины (скорость, разгон, сцепление, нитро), прокачка характеристик за монеты.
6. **Подготовка к заезду** — выбор бустеров (стартовое нитро, щит, +сердце, магнит) за монеты или за рекламу; «Попробовать машину бесплатно на один заезд» (rewarded).
7. **HUD гонки** (см. 3.1) + кнопка паузы.
8. **Пауза** — Продолжить / Рестарт / Настройки / Главное меню.
9. **Результат** — место, очки, звёзды, монеты; кнопки «x3 награды 📺», «Продолжить», «Повторить»; при проигрыше — «Пропустить уровень 📺».
10. **GAME OVER** — обязательные кнопки:
    - **Возродиться** (📺 rewarded) — продолжение с места падения, 2 ❤, 3 с щита; не более 2 раз за заезд; таймер-обратный отсчёт 5 с на кнопке.
    - **Начать сначала**
    - **Магазин**
    - **Главное меню**
11. **Настройки** — музыка, звуки, вибрация, качество графики, схема управления, язык (RU/EN).

## 9. Реклама

### 9.1 Архитектура
`AdService` — единый фасад, ничего не знает о конкретной платформе:
```ts
interface AdProvider {
  init(): Promise<void>;
  showInterstitial(): Promise<AdResult>;   // 'shown' | 'skipped' | 'error' | 'no_fill'
  showRewarded(): Promise<AdResult>;       // 'rewarded' | 'closed' | 'error' | 'no_fill'
  gameplayStart?(): void; gameplayStop?(): void;
  loadingFinished?(): void; happyTime?(): void;
}
```
- Сейчас — `MockProvider`: полноэкранный оверлей «AD 5…4…3…», кнопка закрыть; в dev-панели можно симулировать `no_fill`, `error`, «закрыл раньше времени».
- Позже — подключаемые провайдеры (Яндекс Игры, CrazyGames, Poki, GameDistribution, GamePix, VK Play, AdSense H5 Games) выбором через конфиг сборки, без правки игрового кода.

### 9.2 Места показа

**Interstitial (фуллскрин), агрессивность выше среднего:**
- после каждого завершения уровня (кроме первых 2) — перед экраном результата;
- при «Начать сначала» и «Повторить»;
- при выходе в главное меню из паузы/геймовера;
- при открытии магазина/карты из главного меню — не чаще кулдауна;
- при возврате во вкладку после долгого отсутствия (> 2 мин), если разрешено платформой.
- Глобальный кулдаун **45 с** (настраивается в `AdPolicy`), без показа в первые 60 с сессии, не показывать сразу после rewarded (кулдаун 30 с).
- Перед показом — плашка «Реклама» 1 с (требование многих площадок и меньше раздражения).

**Rewarded (по желанию игрока):**
- Возрождение на геймовере;
- x3 награда за уровень;
- Пропустить уровень;
- Бесплатные монеты в магазине (лимит в час);
- Открытие машины/скина за N просмотров;
- Тест-драйв машины на один заезд;
- Бесплатный бустер перед гонкой;
- Двойной ежедневный приз, дополнительный спин колеса удачи;
- Открыть сундук сразу / удвоить содержимое сундука.

Баннеров нет.

### 9.3 Общие правила (AdGuard + глобальные настройки страницы)
**Во время показа рекламы:**
- игра на **паузе**: `timeScale = 0`, главный цикл не обновляет логику, рендер останавливается или замораживается;
- **звук выключается**: `AudioContext.suspend()` + master gain → 0; после рекламы восстанавливается прежнее состояние (если игрок сам выключил звук — не включаем);
- **ввод блокируется**: клавиатура, тапы, геймпад; после рекламы сбрасываются «залипшие» клавиши;
- после закрытия interstitial в гонке не продолжаем мгновенно — экран паузы/отсчёт 3-2-1;
- награда за rewarded выдаётся **только** по событию «досмотрел»; при закрытии/ошибке — сообщение и никакой награды;
- `no_fill` / ошибка — понятный тост, кнопка не «зависает», игра продолжается;
- блокировка повторного нажатия (одновременно только один показ).

**Всегда (на уровне страницы):**
- отключено контекстное меню (ПКМ, долгий тап): `contextmenu → preventDefault`;
- отключено выделение текста, перетаскивание картинок, `-webkit-touch-callout`, подсветка тапа;
- отключён зум (pinch, double-tap), pull-to-refresh, скролл страницы (`overscroll-behavior: none`, `touch-action: none` на игровом поле);
- `preventDefault` для клавиш, прокручивающих страницу (стрелки, пробел, PageUp/Down) когда фокус на игре;
- автопауза и mute при `visibilitychange` / `blur` (свернули вкладку, пришёл звонок), возобновление — только по действию игрока;
- звук стартует только после первого взаимодействия пользователя;
- никакой рекламы во время активного заезда — только в естественных паузах;
- сообщения платформе `gameplayStart/Stop`, `loadingStart/Finished` в правильных местах;
- нет внешних ссылок и редиректов из игры;
- корректная работа в iframe (размер, фокус по клику), полноэкранный режим по кнопке.

## 10. Звук и музыка (всё синтезом)

### 10.1 Аудиодвижок
Шины: `master → [music, sfx, engine]`, компрессор на мастере, независимые громкости в настройках.

### 10.2 Звуки
| Звук | Рецепт |
|---|---|
| Мотор | 2–3 пилообразных осциллятора + лоупасс, частота от RPM, переключение передач (провал/рост), разные тембры у машин |
| Нитро | розовый шум с полосовым фильтром + свип вверх, «пшик» старта |
| Дрифт/визг шин | шум с узким полосовым фильтром и модуляцией |
| Монета | два быстрых синуса-квадрата (арпеджио), высота растёт в комбо |
| Сердце / щит / магнит | короткие мажорные арпеджио разного тембра |
| Удар / вылет | шумовой удар + низкий «thump» + металлический звон (FM) |
| Буст-пад | «вжух» — свип фильтра |
| Отсчёт 3-2-1-GO | бипы, на GO — аккорд |
| Финиш/победа | фанфара (секвенция), проигрыш — нисходящая |
| UI | клики, «пинг» покупки, звон сундука |

### 10.3 Музыка
- Собственный секвенсор (lookahead-планирование по `AudioContext.currentTime`).
- Инструменты: kick (синус со свипом), snare/clap (шум + тон), хэт (хайпас шум), бас (пила/квадрат + фильтр), лид/арпеджио, пэды.
- Стили по биомам: поп-синтвейв, тропик-хаус, драм-н-бейс для неона и т.д.; прогрессии аккордов и мелодии генерируются по сиду + набор заготовленных паттернов (качество выше чистого рандома).
- Отдельная спокойная тема меню; интенсивность в гонке растёт при нитро и на последних 20% трассы.

## 13. Риски и решения
- **Производительность на мобильных** → инстансинг, тени только около игрока, динамический DPR, пресет Low без постобработки.
- **Качество процедурных машин** → лофт по сечениям + clearcoat + отражения окружения; отдельный «стенд» для настройки пресетов машин.
- **Генератор создаёт непроходимые трассы** → проверки валидности, бюджет сложности, автотест прогоном бота-«оптимиста» по сотням сидов.
- **Звук на iOS** → разблокировка AudioContext по первому тапу, восстановление после `interrupted`.
- **Требования площадок к рекламе отличаются** → всё в `AdPolicy`-конфиге на провайдера.
